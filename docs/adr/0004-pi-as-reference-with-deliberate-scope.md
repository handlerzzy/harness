# 以 Pi 为参考架构，按 SDK 目标取舍

第一阶段交付可嵌入 Python 应用的 SDK，并以真实模型与编码工具闭环及示例验收；Pi 的统一模型协议、适配器、Agent 循环、工具和会话分层作为参考，现有 `0.80.10` 固定源码继续作为可复查的设计依据。用户明确允许按项目需要裁剪或调整字段、模块和服务，因此不将上游全部接口、字段、默认行为或模块布局视为必须一比一兼容的约束，也不以追最新 Pi 为前置条件。取舍以本 SDK 的一致语义、实际使用和维护成本为依据，既有 Python API 如需改变，应明确记录影响。

本决定替代 ADR 0001、0002 对固定核心契约和上游实现的过强约束，保留其中 SDK 优先及参考上游的方向。ADR 0003 的统一模型协议和 Chat Completions 首版范围继续适用；其中 Pi 类型是设计参考，具体字段集由本 SDK 的已确认需求决定，详细交付与测试范围见 [首版规格](../../.scratch/usable-sdk-v1/spec.md)。
