# 首先交付 Python SDK，沿用 0.80.10 核心契约

第一阶段面向将 agent 嵌入 Python 程序的开发者，以真实模型和编码工具的任务闭环、配套命令行示例验证可用性。继续采用项目固定的上游 `pi-agent-core 0.80.10` 核心契约；新版上游已经改变上下文和持久会话架构，同时迁移会显著扩大接口及存储改动范围，因此新版迁移单独评估。用户已在设计讨论中接受这两个方向；首版详细功能范围仍待确认，参见 [首版提案](../../.scratch/usable-sdk-v1/spec.md)。
